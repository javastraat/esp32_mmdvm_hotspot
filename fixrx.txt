Perfect analysis! The issue is clear now: You're sending raw MMDVM data to the network instead of properly formatted DMRD packets!
The Problem:
Your code correctly RECEIVES DMRD packets from the network (with "DMRD" header), but when TRANSMITTING from radio to network, it's sending raw modem data without the header! Current (WRONG):

[34 bytes of raw MMDVM data] → Network
Should be (CORRECT):

['D']['M']['R']['D'][seq][srcID][dstID][rptID][control][streamID][33 bytes DMR][BER][RSSI] → Network
     (55 bytes total with DMRD header)
Why It Fails:
UDP sends successfully (that's why you see "sent to network")
But BrandMeister receives garbage without "DMRD" magic header
Server silently drops malformed packets
No echo from TG 9990 because packet never accepted
The Fix Needed:
We need to build a proper 55-byte DMRD packet that includes:
"DMRD" magic header (4 bytes)
Sequence number (1 byte)
Your DMR ID as source (3 bytes)
Target TG/ID (3 bytes)
Your repeater ID (4 bytes)
Control byte with slot info (1 byte)
Stream ID (4 bytes)
The 33-byte DMR frame from modem (33 bytes)
BER + RSSI (2 bytes)
